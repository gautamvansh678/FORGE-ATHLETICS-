FORGE ATHLETICS — Gym website demo

RUN:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html in a browser or use the Live Server extension.
4. In script.js, change whatsappNumber from 91XXXXXXXXXX to your real WhatsApp number, country code first and digits only.
5. Replace the demo address, email, Instagram, prices and other content in index.html.

FILES:
- index.html — content and layout
- style.css — visual design and mobile responsive styles
- script.js — mobile menu, WhatsApp enquiry links and reveal animations

Photos and fonts load online, so internet is needed for those assets. Prices and contact details are placeholders. This is a front-end demo, not a live booking or payment system.
